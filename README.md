Repositório destinado à disciplina de **Programação Orientada a Objetos (POO)** do **Instituto Federal de Minas Gerais (IFMG)**.

Este repositório reúne exercícios, projetos, implementações e anotações desenvolvidos durante a disciplina, utilizando a linguagem **Java** e aplicando os principais conceitos da Programação Orientada a Objetos.

---

# 🔗 Conteúdos Abordados

Abaixo estão os principais tópicos estudados durante a disciplina.

## 📌 Fundamentos da POO

- Classes
- Objetos
- Atributos
- Métodos
- Construtores

## 📌 Pilares da Programação Orientada a Objetos

- Encapsulamento
- Herança
- Polimorfismo
- Abstração

## 📌 Relacionamento entre Classes

- Associação
- Agregação
- Composição
- Dependência

## 📌 Outros Conceitos

- Modificadores de Acesso
- Sobrecarga de Métodos
- Sobrescrita de Métodos
- Classes Abstratas
- Interfaces
- Tratamento de Exceções
- Coleções (Collections)
